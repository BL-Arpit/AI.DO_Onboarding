Connect your PostgreSQL database

Your server is running. An administrator needs to configure persistent storage before anyone can sign in.

  1. Open your PostgreSQL provider dashboard and copy its connection URL.
  2. In Render, open this web service and select Environment.
  3. Add DATABASE_URL with the connection URL, then select Save and deploy.

For Render Postgres in the same region, use its Internal Database URL. For an external provider, use its full connection URL and required SSL settings.

After redeployment, refresh this page. The app will create its tables and configured test accounts.
